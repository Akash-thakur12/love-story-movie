# Our Love Story - The Movie
A romantic cinematic web app created with love by Khushboo!

## Features
- Cinematic Studio Intro: 'Lights. Camera. Action.' opening tune & Khushboo Studios credits.
- Big-Screen Love Story: High-resolution couple memories & romantic anime illustrations.
- Synchronized Soundtrack: 100% self-contained offline audio with 'Janam Janam' soundtrack.
- Secret Password Surprise: Enter 'I love you' to unlock the 3D Birthday Gift, Fireworks, Cake, and letter!
